# 排版参数(默认值)

> 这些是工具的**默认排版参数**,基准分辨率 **720×1280**(竖屏 9:16)。
> 其它分辨率会按高度比例自动缩放。
> 想改:编辑 `bin/project_kit.py` 顶部的 `LAYOUT` 字典。

---

## 1. 标题(视频正上方)

| 项 | 值 | 对应 spec.json 的键 |
| --- | --- | --- |
| 白框顶边距 | 10.9% 画面高 | `标题样式.顶部占比` |
| 字号 | 38(基准高 1280) | `标题样式.字号` |
| 字色 | 近黑 `#111111` | `标题样式.颜色` |
| 底色 | 纯白 `#FFFFFF` | `标题样式.背景` |
| 框内边距 | 13 | `标题样式.块内边距` |
| 圆角 | 有,自动 | — |
| 是否常驻 | 是,全片 | `标题样式.持续: null` |
| 白框宽度 | 由文字宽度 + 内边距自动决定 | — |

标题内容由公式生成,见 `bin/project_kit.py` 的 `make_title()`:

```
如果{艺人}出生于{年代}s
```

也可以手写标题覆盖公式。

## 3. 为什么用「白字 + 黑描边」而不是黑底色块

白字加黑描边在**亮背景和暗背景上都能读**,不需要额外压一块底色挡住画面。

如果素材整体偏亮、描边不够,把 `描边宽` 调到 4–5 即可。

**判断描边够不够**:抽一帧,量字幕区亮度分布。
亮像素(>180)占比超过 25% 时,建议加粗描边或补底色。

## 4. 从成品视频反推参数的正确方法

如果手上只有成品、要从画面上量参数,注意别用错方法:

| | 方法 | 结果 |
| --- | --- | --- |
| ❌ 错误 | 统计文字邻域的暗像素占比 | 会被画面暗背景稀释,误判为「无描边」 |
| ✅ 正确 | 从白像素向外逐环膨胀,测每环平均亮度 | 紧贴文字的那一环必然是描边,与背景无关 |

工具已封装正确方法:`python bin/measure_layout.py --frames <帧目录>`

## 5. 字体

默认用系统中文字体 `msyhbd.ttc`(微软雅黑粗体),中英文同款。

换字体:改 `bin/project_kit.py` 里 `build_spec()` 的 `字体` 字段,
或直接改生成的 `spec.json`。字体文件需在系统字体目录下。

Windows 字体目录:`C:\Windows\Fonts`
Linux:`/usr/share/fonts` · macOS:`/System/Library/Fonts`

---

## 6. 分辨率适配规则

输入视频宽度不是 720 时,工具会:

1. 缩放到底片宽度 720(高度按比例并取偶)
2. 排版参数按 `输出高度 / 1280` **等比缩放**
   (字号、底距、内边距、描边宽、层间距)

**比例类参数不缩放**(`顶部占比`、`行距`),因为它们本身就是比例。

> 实测踩过:把 `行距` 当像素值缩放会取整成 1,行距就丢了。
> 所以代码里用 `RATIO_KEYS` 显式列出哪些键不缩放。

## 7. 已知的坑(改排版时不要踩回去)

| 坑 | 后果 | 原因 |
| --- | --- | --- |
| 字幕盒高按**单行**算 | 英文换 2 行时中文被挤出画布,表现为「中文消失」 | 块高必须累加**所有换行**的墨迹高 |
| 叠加层与样式列表错位 | 中文取到透明色,完全看不见 | `zip(metas, layers)` 两边要同步过滤空层 |
| 标题按**字体行盒**定位 | 文字在框里偏下,不在中心 | 要量**墨迹**范围再居中,行盒上方有内部留白 |
| RGBA 的 PNG 直接叠到 yuv420p | 某些编码下边缘出杂色 | 叠加前显式 `format=rgba` |
